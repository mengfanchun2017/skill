# memo 模板 — 现有材料原始记录

> 用于 fworch-course Mode B（现有材料课程化）的 `-memo` 层。
> memo = **原始记录**，忠实呈现课程/案例原始材料，不做改写。
> 命名：`<slug>-<weekN>-memo`（周）/ `<slug>-<case>-memo`（案例）。

## 周 memo 骨架

```
# Week N：<英文主题>

> 本 memo 合并课程官方材料：<源1>、<源2>、<源3>。来源见课程附件。

## <源1 标题，如「要点讲稿」>
<源1 正文，清洗页眉页脚、重排段落>

## <源2 标题，如「讲义卡片」>
<源2 正文>

## <源3 标题，如「视频逐字稿」>
<逐字稿，按 Video N 分节>
```

## 案例 memo 骨架

```
# <案例英文标题>（<中文主题>）

> <一句话来源说明>

## 原文正文
<案例原文全文>
```

## 清洗要点

- 去页眉页脚（书名/页码/周标题等重复行）
- 合并被 PDF 硬换行拆断的句子；bullet 标记与内容并回一行
- 保留原文语言（英文材料不翻译——翻译放 update 层）
- 表格尽量还原为 Markdown 表格
