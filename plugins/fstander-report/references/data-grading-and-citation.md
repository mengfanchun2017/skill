# 数据分级与引用纪律（Data Grading & Citation）

> 报告写作的**数据真实性核心**，动笔取数前必读。讲四件事：数据如何分级、各维度的合格来源、正文如何引用与勾稽、交付前如何核对数字准确性。
> 优先级高于排版与篇幅；与别处冲突时以本文件为准。
> 适配：取数走 fsearch（Tavily + Exa），格式落地走 ffeishu（见其 write-checklist §2）。

## 一、三级数据分级

进入正文或表格的每条数据，先归入下面三个可信度等级，据此决定能否当展示数值、措辞要多克制。

### 第一级 · 可直接作为事实陈述（最高可信）

- **一手官方数据与权威机构原文**——政策/法律原文（政府网、人大网、部委）、监管与交易所公告、公司年报/季报/公告/招股书、官方统计（统计局/央行/海关/主管部委）、官方通讯社、署名带日期的券商研报原文。
- **权威数据库口径的市场/财务数字**——市场规模/增速/份额、价格、毛利率、产能利用率、融资、估值、财务指标（金融数据库/行业数据库）。

一级数据可直接写成事实（"披露 / 为 / 显示"）。

### 第二级 · 可引用，但须标注来源、措辞需限定

- 权威/主流财经媒体与行业垂直媒体的**原创报道**（署名原创，非一手发布）；
- **行业协会与第三方研究机构数据**（统计、榜单、市占率/出货估算——是测算而非披露）；
- 券商/机构**对未披露口径的一致预期/估算**。

二级数据引用时必须**显名归因并限定措辞**——"据 XX 协会数据""据券商研报估算""据 IDC 测算"，用"据/约/或/可能"，**不得写成一手的确定事实**。

### 第三级 · 仅作线索，原则上不入展示

- 聚合平台/数据汇编站、自媒体、UGC、论坛（前瞻/智研/中商/华经，头条、雪球、股吧等）；
- 市场传闻、社交讨论、无署名来源、来源不明的二手转载。

三级信息**不得作为任何展示数值的依据**。最多是待核验线索：必须顺藤摸到一级（或至少二级）原文核验后，引用那个更高等级的来源；**核验不到就不展示**——按数据缺口处理，正文标"公开信息有限"，绝不补造。

## 二、来源级别判定

判断一个数字能不能进正文，两个维度必须**同时满足**：

| 维度 | 要求 |
|---|---|
| **来源级别** | 底层出处必须是一/二级可靠信源。第三级不得作为某市场数字的唯一来源——确无更高级别时须交叉互证另一独立来源，否则按缺口降级。 |
| **取数一致性** | 市场/财务数字的展示值以权威数据库/官方统计/一手披露口径为准；新闻/二级来源里的同类数字只能作线索核验后再用，绝不直接当展示值。 |

判定示例：

- ✅ `277GW`，出处国家能源局（官方统计，一级）——出处一手官方。
- ✅ 券商研报原文里转述的公司披露硬数字：出处券商研报（一级），正文可写成事实。
- ✅ `CR5 62%`（券商对未披露口径的估算，二级）：正文写"据券商估算"。
- ❌ `CR5 62%`，唯一来源是雪球（三级）——须换一手/数据库/券商研报原文/官方来源，或交叉互证，或按缺口降级。

## 三、每个维度的合格来源（举例）

| 维度 | 首选来源举例（级别） |
|---|---|
| 市场规模 | 统计与部委月度数据、行业数据库（一级）；行业协会统计公报须显名"据 XX 协会"（二级） |
| 增速 / CAGR | 由一级规模数据自行测算（标"本研究测算"并写公式），或数据库直接口径（一级） |
| 竞争格局 / 集中度 | 券商研报原始测算（一级研报原文）；第三方调研机构须显名（二级估算） |
| 价格 | 价格数据库/行业协会报价、交易所或现货市场报价（一级数据库口径） |
| 盈利 / 利润率 | 公司年报/季报、财务数据库（一级） |
| 产能 / 利用率 | 公司公告与年报（一级）；行业协会、券商产能跟踪须显名（二级） |
| 估值 | 金融数据库，须标 TTM/静态/动态(LYR) 与时点（数据截至 YYYY-MM-DD）（一级） |
| 政策 | 部委原文、政府网、正式文件（一级） |
| 需求 / 出货 | 官方统计、海关数据（一级）；行业协会出货统计须显名（二级） |
| 出海 / 海外 | 海关进出口、目的国官方统计（一级）；IEA/BNEF/IDC 海外报告须显名（二级） |
| 成本 | 公司年报成本拆分、价格数据库（一级）；券商成本曲线测算（二级估算） |
| 融资 / 并购 | 公司公告（定增/可转债/IPO）、交易所披露、融资库（一级） |
| 重点公司 | 仅用法定信披（年报/公告/交易所披露），样本取代表性龙头与典型品种（一级） |

> 行业协会与第三方研究机构数据是**二级**，须显名归因；只有券商研报原文在"机构"中属一级。券商*自己估算*未披露口径时仍属二级。

## 四、正文角色与允许措辞

**结论强度不得超出证据档位**：

| 正文角色 | 正文允许写法 | 条件 |
|---|---|---|
| 硬事实 | 显示 / 为 / 披露 | 须一级来源（或本研究测算） |
| 官方/公司表态 | 公司称 / 官方表示 | 官方或公司的定性表述 |
| 券商估算 | 据券商估算 / 研报判断 | 券商对未披露口径的测算 |
| 机构/协会测算 | 据 XX 机构/协会测算 | 研究机构/协会的统计或测算 |
| 媒体观点 | 据报道 / 市场讨论 | 媒体观点或市场说法 |
| 本研究测算 | 按公开数据测算 | 须写清公式/口径与假设 |
| 作者推断 | 这可能意味着……，后续需验证 | 不得写成定论 |

要点：

- 产能、规划、目标、市占率、行业 CR_n、管理层展望等**容易被拔高**的数据，必须带相称限定语与保留条件（如"据券商研报估算……，公司年报未披露该口径""规划产能不等同于已完全释放"）。
- 券商研报原文里*转述公司披露的硬数字*可写成事实；券商*自己估算*未披露口径的数字，必须写"据券商估算"。
- 同一指标多源差异 >30% → 并列展示并解释口径，不取平均、不只取单源。

## 五、引用机制：正文数字引用 + 文末参考文献

正文用**紧凑的数字引用**承载可溯源，不在段落或表格里写长串来源名或完整 URL：

- **来源台账与阅读顺序编号**：检索阶段把每个来源连同级别/基期/**源值（原文数字＋单位＋口径，照抄准）**登记成一份**来源台账**（写在对话上下文/工作笔记，不落本地盘）；台账先只记临时标识与源值，不预分配最终编号。**最终引用编号按正文成稿后的首次出现顺序分配**：读者从上到下第一次遇到的新来源为 `[1]`，第二个为 `[2]`，递增；同一来源多处引用复用同一编号。若改稿导致某来源首现位置变化，必须同步重排正文编号与文末参考文献。
- **正文出现的每个具体数据点（规模/增速/份额/价格/毛利率/估值/融资/产能/需求/政策标准/竞品指标等量化或具名硬事实）都标紧凑引用** `[1]`、`[2]`、`[1][3]`，**位置统一为该数据所在句子的句末、句号之前**：一句含一个数据点或多点同源 → 合并放句末（"2026年中国光伏新增装机277GW、同比增长28%[1]。"）；一句含多点**异源** → 每点后紧跟其引用以免对错（"组件均价0.68元/W[2]，硅料毛利率约35%[3]。"）。"凡数据必有句末标注"是底线，不能只标关键句、其余裸奔。例外：① `本研究测算`值句末写"（本研究测算，公式见上）"而非 `[n]`，其输入数字仍各带 `[n]`；② 表格走表下"资料来源"行（单元格内需要时可加 `[n]`），不逐格标注。
- 表格在表格正下方加一行 `资料来源：<具体机构/文件>`，命名到具体机构或文件名（如"国家能源局，本研究测算"），不写"行业调研""公开资料"这类空泛写法。
- 报告末尾给一个**编号参考文献**列表，把每个引用编号映射到：来源名、发布或访问日期、相关字段/章节、**真实可点击的 URL**、一句话说明它支撑哪个判断。
- **引用勾稽（强制）**：每个正文引用编号都要有对应文末条目；每个文末条目都要在正文至少被引用一次。

参考文献合规要求：

- 只列有公开原文链接的来源；无公开链接的数据库数字照常支撑判断，但作为"未公开链接的尽调输入"在来源说明里披露，不占编号引用。
- 不得出现空条目、仅域名首页链接、失效链接、纯文字数据库引用，或描述与所引判断不符的来源。
- 按正文首次引用顺序使用 `[1]`、`[2]` 格式誊抄；不要用 `1.` / `2.` 作为参考文献编号；同一机构不同报告分列。

## 六、数据准确性核验（写作中 + 交付前）

基准是台账里照原文抄准的源值：正文每个 `[n]` 数字都应等于台账第 n 条源值。**写作中**边写边核，**交付前**对成稿逐项复核六维：

1. **值＝源**：等于源值（仅允许声明过的四舍五入）；防抄串位（277↔227）、错量级（亿↔万、GW↔MW）、用旧值。
2. **口径＝源**：单位/口径一致（出厂/零售、含税、销量/销售额、收入/出货/装机、全球/中国）；口径不同须按写明公式换算成 `本研究测算`，否则不写。
3. **基期＝源**：与源一致并在正文标注。
4. **档位**：重核第二节两维红线。
5. **前后一致**：同一指标在摘要/正文/表格取值一致；多源差异 >30% 按第四节并列、不取平均。
6. **测算可复算**：`本研究测算` 值能由所写公式与带 `[n]` 的输入复算得出。

不过关就改成源值、换算或降级/标缺口，**绝不靠改小数点、凑平均、模糊措辞糊过去**。缺口本身就是结论（见第八节）。

## 七、关键事实硬门槛

决策关键的事实需要具体、可核查的支撑。除非来源列表里有直接可用的文章/文件链接、官方记录 URL、数据库记录 URL 或用户提供的文件链接支撑该确切主张，否则**不要把它写成已确认的事实**。

适用于：市场规模、增速、渗透率、政策标准、补贴、基准、排名、"最大/最高/第一"类主张；融资金额/轮次/投资方/估值/并购/IPO；价格、毛利率、产能、利用率、良率、出货量、库存、交付时间表；具名客户关系、产能预定、合作、诉讼、专利、安全事件。

若来源只是泛泛首页、域名级 URL、无署名摘要、社交帖或未经核验的 PR 表述，则**降级**该主张，用"公开信息有限""据报道""公司口径称""需以官方核验"等措辞，不要放进核心判断或估值结论当已确认事实。

## 八、缺证据的处理

若证据缺失，不要用泛泛之词填补。写清：缺的是什么、为什么重要、现有最佳替代/代理指标是什么、下一步如何核验、什么答案会改变判断。

**缺数据本身是一个分析结论**，如实暴露，绝不通过切换隐藏来源或补造来填补。

## 九、竞品证据

对具名竞品，尽量核验：公司状态（上市/未上市/开源/国资）、融资（最近轮次、金额、日期、领投、累计、可信估值）、经营成熟度（披露的收入/ARR、客户类型、地域、部署模式）、战略禀赋（渠道、产能/成本曲线、技术基准、合规本地化、客户关系、资本）。若公开来源无融资数据，标"公开来源未披露"而非猜测。
