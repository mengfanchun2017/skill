# 报告原型与结构骨架

> 4 套模板（`research.md` / `analysis.md` / `comparison.md` / `proposal.md`）是「内容功能」维度的骨架。
> 本文件补一个**正交维度**：按**读者用途**定原型——同一份素材，读者拿它干什么，决定结构、篇幅、图表标题写法。
> 开工前先回答「这份报告的一句话是什么」，再选原型（见 `report-card.md`）。

## 按读者用途选原型

| 读者要 | 原型 | 特征 |
|---|---|---|
| 引用你的数字 | 学术型 | 竖版、方法论透明、图表编号 Figure、预先反驳自己 |
| 拿去开会说服人 | 咨询 deck 型 | 一页一结论、标题就是结论句 |
| 理解一个群体 | 调查型 | 双栏、问卷原题随图、大数字视觉锚 |
| 查具体数据 | 研报型 | Exhibit 编号、表格密度高、中性描述标题 |
| 理解一个领域并据此行动（无背景） | 科普型 | 三幕骨架、场景开篇、结尾交付工具箱 |

选错原型是最贵的错误——把要被引用的东西做成 deck，没人能引；把开会用的做成 60 页学术报告，没人会读。

**一句话判据**：写不出「读者会复述给别人的那一句话」，说明还没有报告，只有素材。

## 各原型的结构要点

### 学术/研究型
```
摘要（编号事实，能独立读懂）
1. 研究问题与证据基础
   1.1 本研究相对既有文献的位置 ← 最常被跳过，也最能看出懂不懂行
   1.2 这批证据能回答与不能回答的
   1.3 证据分级（不同来源支撑不同强度结论）
   1.4 样本框、纳入排除标准、口径统一规则
2-N. 发现（每章一个主题）
   每章：机制分析——为什么，给竞争假说而非单一说法
   末章前：局限性与替代解释，诚实说出没排除掉的
   结论：这些发现合起来意味着什么（必须超出摘要）
参考文献
```
**1.1 是学术型的分水岭**——不交代相对既有研究的位置，等于宣称这个领域从你开始。

### 咨询 deck 型
```
执行摘要（3-5 条，每条一行）
方法论页（整页，样本构成图）
主体：一页一结论
   ├ 小标签（这页属于哪一节）
   ├ 大号结论句标题（一整句话）
   ├ 图表（自带问题式小标题）
   └ 数据源行
关键行动建议（3-5 条）
```
**一页一结论是硬约束**。一页塞两个结论，读者两个都记不住。

### 调查型
```
方法论摘要（样本量、field 时间、加权方式）
执行摘要（Key Findings，5-10 条）
主体：双栏正文 + 嵌入图表
   每图下方：问卷原题全文 + Base + N
分市场/分群体章节
```
**问卷原题必须随图给**。**年比年变化标 pp（百分点）不标 %**：「上升 9pp 到 39%」不写成「上升 9%」。

### 研报型
```
首页：日期时间戳 + 分析师署名 + 一段 thesis
Exhibit 1-N（编号连续）
   每个 Exhibit：中性描述标题 + 图/表 + Source 行
分板块/分地区数据表
估值与风险
```
**标题用中性描述不用结论**——查数的读者要索引，不是被说服。

### 科普型（三幕骨架）

面向无背景读者。**它和学术型的差别不在严谨度，在叙述骨架。**

```
序章        一个场景 → 一个悬念 → 这本书分三幕
第 1 幕 建立      这个东西怎么来的，为什么当初所有人都觉得它对
第 2 幕 推翻      有人去查了，结果不一样（这里放竞争假说与替代解释）
第 3 幕 剩下什么   清算之后还站着的东西，以及读者该做什么
尾声        回到序章那个场景，收束
附录        文献表
```

**六个承重手法**（都是可检查「做没做」的动作，不是风格）：

1. **入口是一个人在一个具体时刻。** 每章第一段写一个具体的人/时刻/事，不写定义。
2. **先给读者一个他自己会想到的错答案。** 让读者真的停下来产生一个答案，再推翻它。写成设问句自答不算。
3. **比喻必须承重。** 检查方法：写完比喻，试着用它推出一个你没直接说过的结论。推不出来就是装饰，删。
4. **数字必须被翻译。** 每个数字后跟一个身体尺度对照物（「1 个 MET」→「快走约 3–4 个 MET」）。翻译是加在旁边的，不替换原数字。
5. **把不确定写进正文，不写进脚注。** 用竞争假说给机制；主动降级结论比等别人来降级体面。
6. **结尾是工具，不是总结。** 最后一章交付一套可迁移的判断方法——3–5 个问题 + 红旗清单，且问题**不要求专业知识**。

**唯一硬约束**：读者读完带走的是判断力，不是结论。

> 科普型不降低严谨度，它换地方放：效应量/样本量/口径搬进侧栏，局限性拆进相关段落，
> 完整数据表随交付物给文件。`research.md` 的飞书结构可用，把学术腔换成叙事骨架。

## 附录放什么

**附录是参考文献表，不是数据表的转印。**

一条来源一行：机构或作者、标题、年份、URL。同一份来源被二十个数字引用过，
在附录里仍只出现一次——**附录长度跟来源数走，不跟数据点数走**。

口径不搬进附录。口径写在用得到它的那一页：正文括号、图注的 N、侧栏，
且只写给那些「读者知道了口径会改变判断」的数字（争议值、多口径打架的值、自己复算的值）。
其余数字的口径留在数据表里随交付物一起给。

**体量闸：附录不超过正文的 10%。** 超了就不是严谨，是把工作过程当成了交付物，
和「报告里不写我是怎么做的」是同一条规矩的两个面。

判据一句话：**读者会在什么情况下翻到附录？** 想核某个数字出处 → 一行文献就够。
想知道你怎么算出来的 → 那是方法论节的事，写一段可复用规则，不是堆三百条个例。

## 篇幅基线

内容写完再调篇幅，不要为凑页数灌水。**页数不够时能加的只有两种东西**：
真正缺失的横截面分析、关键数字速查表。凑字数的过渡段落会被一眼看穿。

**加附录不算加内容**——把数据表逐条印进文末能瞬间多出上百页，而没有一个读者会读。
