# 面试准备模板骨架

> fwstd-interview 各产物骨架。飞书格式（lark-table 822 等）走 ffeishu。

## 岗位画像

```
# <岗位名称> 岗位画像
> 依据：<JD/公告来源>；级别：<如 9B>

## 岗位定位（一句话）
## 核心职责（3-6 条，来自 JD）
## 任职要求
### 硬性（学历/经验/资质）
### 能力（技能/素质）
## 级别定位（<9B> 意味着什么：独立程度/责任范围）
## 成功标准（做到什么算称职）
## 汇报关系与协作部门
```

## 组织与行业

```
# <岗位>-组织与行业
## 应聘单位概况（性质/规模/机队体量/枢纽/最新战略与新闻）
## 组织架构（机队管理归属 + 协作关系；fdiagram 可画）
## 行业现状（规模/格局/政策/周期）
## 岗位在价值链中的位置
## 未来 3-5 年趋势
```

## 专业知识地图（SFIA 三层）

```
# <岗位>-专业知识地图
> 掌握程度：入门/熟悉/精通（对照 <级别>）

| 能力域 capability | 技能 skill | 关键知识点 knowledge | 掌握程度 |
|<lark-table 822>|
```

## 能力素质模型

```
# <岗位>-能力素质模型
## 能力素质项
| 能力项 | 定义 | 初级 | 中级 | 高级 | 权重 |
## 差距分析
| 岗位要求 | 我的现状 | 强项/待补/可迁移 | 补齐策略 |
```

## 问题库

```
# <岗位>-问题库
| 问题 | 类型 | 轮次 | 考察点 | 难度 | 答案要点 | 知识域 | 需STAR |
```
分类：自我介绍 / 动机 / 专业 / 案例情景 / 行为(STAR) / 未来思路 / 反问。

## 问答素材

```
# <岗位>-问答素材（STAR）
## 自我介绍（1min / 3min）
## 动机类（故事线：过去→为什么转→为什么这家→未来贡献）
## 专业类（结构化框架：定义→分点→举例→回归岗位）
## 行为类（STAR + 启示）
## 情景类（诊断→分析→建议）
每题标时长 + 可能追问
```

## 未来工作思路（核心）

```
# <岗位>-未来工作思路
## 一、现状与问题诊断（本单位机队，公开数据 + 3-5 痛点/机会）
## 二、工作理念（一句话主张）
## 三、分阶段规划
| 阶段 | 时间 | 目标 | 动作 |
| 短期 | 0-30天 | 熟悉摸底 | … |
| 中期 | 30-90天 | 可落地改进 | … |
| 长期 | 90天-1年 | 系统性工作 | … |
## 四、重点举措（2-3 个，做法 + 量化预期）
## 五、所需支持与协同
## 六、风险与应对
```

## 模拟演练清单

```
# <岗位>-模拟演练与逐轮清单
## 逐轮作战清单
| 轮次 | 考察重点 | 我的素材(链接) | 开场/收尾 | 备注 |
## 模拟问答记录（题/答/反馈/改进）
## 临场要点（自我介绍定稿 / 反问清单 / 陷阱题应对）
## 物料清单
## 心理与复盘
```
