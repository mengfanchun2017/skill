# Step 1 组织与行业认知

> 面试线 Step 1。产出《<岗位>-组织与行业》。目的：搞清"我加入的是什么组织、这个行业在发生什么"。

## 输入
- 岗位画像（Step 0 产物，fetch 飞书）
- 应聘单位名称、岗位、级别

## 输出
飞书子文档《<岗位>-组织与行业》。返回按 `comm-contract.md`。

## 内容骨架（模板见 fwstd-interview）

1. **应聘单位**：性质（国企/民营/央企）、规模、机队/业务体量、基地/枢纽、近年战略与新闻（3-5 条最新）
2. **组织架构**：机队管理职能部门归属（运控 / 机务工程 / 规划 / 商务）、上下级关系、与哪些部门协作
3. **行业现状**：行业规模、竞争格局、政策（民航局规章）、周期（疫情后复苏）
4. **岗位所在的业务域**：机队管理在航司价值链中的位置（飞机引进→运营→退役）
5. **趋势**：机队管理未来 3-5 年趋势（国产大飞机、绿色航空、数字化）——**面试加分项**

## 流程
1. 调 fsearch 三源搜（单位官网/年报、行业报告、新闻、民航局）
2. 调 fresearchframe 按 market 领域框架整理
3. 调 ffeishu 创建子文档（父文档 = 配置 `root_doc_url`）
4. 返回 `{status, doc_url, notes}`

## 依赖
fsearch / fresearchframe / ffeishu
