# Step 3 能力素质模型

> 面试线 Step 3。产出《<岗位>-能力素质模型》。目的：明确岗位要的**硬能力 + 软素质**，并做**自身差距分析**。

## 输入
- JD 任职要求
- 用户个人背景（`candidate_background`）
- 知识地图（fetch）

## 输出
飞书子文档《<岗位>-能力素质模型》。返回按 `comm-contract.md`。

## 内容骨架
1. **能力素质项**：从 JD 抽（如"数据敏感性""沟通协调""法规意识""成本意识""项目管理"）
2. **每项定义 + 行为锚点**（初级/中级/高级分别什么表现）——对标 9B
3. **权重**：哪些是核心项（面试官最看重）
4. **差距分析表**：岗位要求 vs 用户现状 → 强项 / 待补 / 可迁移（重点写"可迁移能力"：把用户已有经历映射到岗位要求）
5. **补齐策略**：每项待补的速成路径（读书/政策/案例）

## 流程
1. 抽能力项 → 定义 + 锚点（fsearch 补行业通用素质模型）
2. 与用户背景做差距分析（用 AskUserQuestion 核实背景细节，不臆造）
3. 建飞书子文档；返回
