# Step 8 面试成稿包（定稿）

> 面试线 Step 8（末步）。产出《<岗位>-面试成稿包》。目的：把全链条产出**收口成一份可打印/可速览的最终材料**，用户面试前只看这一份。

## 输入
- 全部前置产物（fetch）

## 输出
飞书父文档（orchestrator 的 root）内的**总目录页**《<岗位>-面试成稿包》。返回按 `comm-contract.md`。

## 内容骨架
1. **导航目录**：链接到全部子文档（岗位画像/组织行业/知识地图/能力模型/问题库/问答素材/工作思路/模拟清单）
2. **一页速览（Cheat Sheet）**：
   - 岗位核心（一句话定位 + 3 个关键职责）
   - 我的三个卖点（可迁移能力）
   - 工作思路 3 句话版
   - 自我介绍 1 分钟定稿
   - 反问清单
3. **交付材料正文**：按用户要求的**最终交付形态**（如"岗位认知 + 未来工作思路"两篇），合并成正式文档
4. **检查清单**：面试前逐项打勾

## 流程
1. fetch 全部子文档 → 汇总
2. 生成速览 + 交付正文
3. 建/更新飞书父文档（成稿包）；将 root 的「子文档索引」小节补齐
4. 返回 → orchestrator 置 `status=completed`、`current_step=9`
