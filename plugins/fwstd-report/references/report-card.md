# 报告卡片（Report Card）

> 正式写报告前的确认清单。fworch-report Step 0 调用。

## 确认项

| 项目 | 内容 |
|------|------|
| 目标读者 | <谁会读、用在哪：内部决策 / 客户提案 / 公开分享> |
| 读者用途 | <引用数字 / 开会说服 / 理解群体 / 查具体数据 / 理解领域并行动——决定原型，见 report-prototypes.md> |
| 报告原型 | 学术 / deck / 调查 / 研报 / 科普（按读者用途选，非必填） |
| 模板选择 | research / analysis / comparison / proposal |
| 一句话判断 | <读者会复述给别人的那一句话；写不出说明还没想清楚> |
| 预估字数 | <填写> |
| 章节大纲 | <列出 H1 章节标题> |
| 数据来源 | <列出> |
| 不确定性项 | <列出已知的 uncertain 点> |
| 图表计划 | <列出计划中的图 + 每图结论式标题> |
