# 判断主线底稿（Insight Spine）

> 报告写正文**之前**必做：先想清楚"这篇报告要证明什么判断、凭哪几个核心数据、哪些信号能验证或推翻"。
> 之后写每个板块都回头对照它，保证全文一条主线，不写成"什么都讲一点的资料汇编"。
> 适用于任何有论证诉求的长报告（研究/分析/对比/方案）。

## 一、什么时候做、产出什么

- **时机**：调研取证（fresearchframe/fsearch）做完、动笔写正文**之前**。
- **产出**：底稿**写在对话上下文里**，尽量 5 分钟内写完（工作中间件，不进入正文；本地文件跨回合会丢）。写每批正文时对照它当尺子。
- **原则**：先有判断、再写正文。若证据不支持最初的判断，**先改这张表，再动正文**——不要都写完了才发现主线立不住。

## 二、七格表

逐格用真实内容替换 `…`：

```markdown
# {主题} 判断主线底稿

## 一句话主线
（一句话说清核心判断。要能被验证、能被推翻，不能是"空间大、长期看好"这种正确的废话。）

## 七格表
| 格子 | 内容 |
|---|---|
| 决策问题 | 把用户那句话改写成一个**可判断**的问题。 |
| 市场共识 | 大家已知道、已被定价的部分是什么。 |
| 非共识判断 | 本报告真正要证明、和共识不一样的判断是什么。 |
| 核心数据 | 支撑主线的 **3–5 个关键数字**（规模/增速/份额/价格/毛利率等），每个带单位与年份。后面写正文要反复用、不能自相矛盾。 |
| 因果链 | 用"驱动 → 传导 → 结果"写一条链，至少 4 个节点。 |
| 价值迁移/利润池 | 钱正从哪个环节流向哪个环节，谁受益、谁受损。链式行业按上/中/下游写。 |
| 验证与证伪信号 | 列 **5 个左右**带编号信号 T1、T2…：哪些发生→印证主线（正向），哪些发生→推翻主线（反向），各注明阈值或方向。 |

## 三情景速览（先把结果想好）
| 情景 | 关键假设 | 规模/结果 | 利润/毛利率方向 | 对结论的含义 |
|---|---|---|---|---|
| 乐观 | … | … | … | … |
| 中性（基准） | … | … | … | … |
| 悲观 | … | … | … | … |

## 各板块要证明的子命题（**内部抓手**：写正文时化成开头"亮明判断"主题句，不要照抄成标签）
| 板块 | 子命题 | 对主线的作用（印证/限定） |
|---|---|---|
| … | … | … |
```

## 三、填表的 6 条要点

1. **主线要"可证伪"**：能写出"如果 X 发生，这个判断就错了"才算合格。
2. **核心数据要少而硬**：只挑 3–5 个真正支撑主线的数字，宁缺毋滥。这几个数字是全文的"锚"——正文里出现的规模/增速/价格/份额都要和它对得上，不能这段说 100、那段说 80。数字须有可溯源出处（见 `data-grading-and-citation.md`）。
3. **共识 vs 非共识要真的不同**：读起来差不多 = 没有预期差，重写。
4. **利润池/价值迁移要点名**：写清"钱从谁流向谁"。
5. **T 信号要可观测**：每个 T 要能在公开数据里跟踪（招标均价、并网量、毛利率、核准节奏等），不要写"景气度改善"这种没法量化的。至少 1 个正向、1 个反向。
6. **三情景先写结果再写假设**：强制先把**结果**（规模/利润方向/结论含义）想清楚，避免到时候只罗列假设、不给结果。

## 四、写正文时怎么用这张表

- **每个板块开头**：照"子命题表"把子命题写成一句**"亮明判断"的主题句**（有态度、可被证明的论断），正文随后去证明它。**不要写成"本板块要证明的子命题：……"这类标签式说明**——子命题是内部抓手，读者应通过论证看出你在证明它。
  - ✗ 反面（标签式，禁用）："本板块要证明的子命题：利润池正从中游整机向上游元器件迁移。"
  - ✓ 正面（论断式主题句）："激光行业的利润正在沿产业链上移——中游整机在价格战中毛利已压至 12–20%，而上游泵浦源、特种光纤等核心元器件仍维持 50–70% 的高毛利，这一剪刀差正在重塑各环节的价值分配。"
- **每个板块结尾**：放一个 `回扣主线` 小节（标题就叫"回扣主线"），用 2–3 句先**总结本章**、再说清本章结论**印证 / 强化 / 限定**了核心判断、和哪个 T 信号联动。兼具本章小结与回到主线的作用。**发现反证要如实写**。
- **执行摘要**：开头就要让读者知道"大家已知什么（共识）"和"本报告新增的判断是什么（非共识）"，并点出那 3–5 个核心数据。
- **趋势/机会板块**：把七格表里的 T 信号汇成一张"信号验证清单"表（观察指标/阈值或方向/看多看空/数据来源）。
- **情景板块**：直接把"三情景速览"展开成正文，每档**必须给结果**。
- **风险提示**：每条尽量指回某个 T 信号（哪个信号超阈值→这条风险兑现）。

> 一句话：**这张表是写作前的"判断骨架"，不是附录。** 写正文全过程拿它当尺子，写完每段回头看"有没有跑偏、数字有没有打架、是不是在为主线添砖"。
