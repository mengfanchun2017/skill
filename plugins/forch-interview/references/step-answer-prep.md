# Step 5 问答素材（STAR + 通用）

> 面试线 Step 5。产出《<岗位>-问答素材》。目的：为 Step 4 问题库的重点题，写出**可直接背的答案**。

## 输入
- 问题库（fetch）
- 用户个人背景（`candidate_background`）

## 输出
飞书子文档《<岗位>-问答素材（STAR）》。返回按 `comm-contract.md`。

## 方法
1. 挑**高频 + 高权重**题（约 20-30 道），逐题写答案要点（不必每题长答）
2. **行为类/经历类**用 **STAR**（Situation 情境 / Task 任务 / Action 行动 / Result 结果）+ 收尾一句"启示/与岗位的关联"
3. **专业类**给"结构化答题框架"（先定义 → 分点 → 举例 → 回归岗位）
4. **动机类**给"故事线"（过去经历 → 为什么转 → 为什么这家 → 未来贡献）
5. 每组答案标注**时长**（30s/1min/2min）

## 硬规则
- **答案基于用户真实背景**：缺经历时用 AskUserQuestion 问，不编造经历
- 转行/零经验者：用**可迁移能力**叙事（"我做过 X，其中 Y 能力可迁移到机队管理"）
- 每题给"可能追问"1-2 个 + 应对

## 流程
1. fetch 问题库 → 选重点题
2. 结合用户背景写答案（缺信息则问）
3. 建飞书子文档；返回
