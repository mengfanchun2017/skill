# technical 维度 — 技术评估框架

> fresmethod `technical` 维度方法论。适用于技术评估、库/框架对比、选型调研。

## 字段

- **basic_info**: project_name, version, license
- **capabilities**: core_features, integrations
- **adoption**: github_stars, contributors
- **ecosystem**: third_party_packages, community_activity

## 解读要点

- 版本/license 要标明查证时间与来源（官网/repo），不用记忆值
- capabilities 分"核心能力"与"集成能力"，别把营销列表当事实
- adoption 给趋势（star 增长、contributor 变化）而非单点快照
- ecosystem 看社区活跃度（issue 响应、发布节奏），不只看包数量
