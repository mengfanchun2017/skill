# 中文科研语体规范（英译中，规避翻译腔）

> 来源：深度调研 [A][D] 中"规避翻译腔"结论 + 中文科技论文语体通识。
> 供翻译 System prompt 与 QC Fluency 维度引用。

## 总原则
学术英语长难句多（嵌套从句 + 被动 + 名词化），中文科技语体惯用**短句 + 逻辑词**。
翻译不等同"逐词对译"，要**重组句子**使符合中文表达习��，同时保留原文全部信息。

## 句式处理
1. **切分长句**：英文一个 40+ 词长句，中文拆成 2-3 个短句，用"由于/因此/结果表明/与此同时"等连接。
2. **化被动为主动/无主句**：
   - `The experiment was conducted` → `我们进行了实验` / `进行了实验`（科研惯用无主句）
   - 避免"被进行""被观察到"式硬译。
3. **名词化还原**：英文大量"the development of / the implementation of"名词结构，中文还原为动词"开发/实现"。

## 术语处理
4. 已约定俗成的术语用**规范译名**（各学科各有标准，遵循术语库）。
5. 首次出现的缩略语：**标注全称**（如 `CRISPR（成簇规律间隔短回文重复序列）`），后续直接用缩写或中文名。
6. 专名（作者名、机构、期刊、软件名、基因名）按惯例：**保留原文**或音译，遵循术语库 doNotTranslate。

## 格式与数据（逐字保真，不可意译）
7. **公式、变量、图表号、参考文献编号**：原样保留，`Fig. 2` → `图 2` 可译，但编号不可变。
8. **数字、单位、日期**：数值原样，单位按中文惯例（`mm`→`毫米`，但保持数值精度）。
9. **统计量符号**（p 值、置信区间、效应量）不可改动。

## 标点
10. 中文用全角标点 `，。：；（）`；引导语"如图所示""结果表明"用逗号而非冒号的场景按中文习惯。

## 反例（翻译腔）
| 翻译腔 | 中文规范改法 |
|--------|-------------|
| 该实验被进行以验证假设 | 本研究进行了实验，以验证该假设 |
| 数据的收集和分析被完成 | 我们收集并分析了数据 |
| 结果表明了显著的差异 | 结果表明存在显著差异 |
| 这一结果的重要性不能被忽视 | 这一结果的重要性不容忽视 |
