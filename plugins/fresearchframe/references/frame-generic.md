# generic 维度 — 通用概览框架

> fresearchframe `generic` 维度方法论。适用于通用市场/技术概况调研。

## 字段

- **name, description, category, tags**
- **overview**: what_is_it, key_characteristics, current_status
- **performance**: metrics, benchmarks, comparison
- **adoption**: user_scale, market_share, growth_rate

## 解读要点

- 先给定义与边界（what_is_it / key_characteristics），再给现状
- performance 要有可比口径（同维度、同时间窗），不给孤立数字
- adoption 区分"用户规模"与"市场份额"，标明数据来源与年份
