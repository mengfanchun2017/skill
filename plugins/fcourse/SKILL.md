# fcourse — 系列课程创作

> **输入**：你给一个飞书需求文档链接（含主题/目标受众/概览）
> **输出**：飞书父文档 + 子文档体系（调研 → 体系 → 逐课教案 → 练习）
> **定位**：商业分析 / 数据分析 / AI 能力 / 知识管理

**前置条件**：本 skill 依赖 ffeishu 做飞书文档操作（新建/更新/验证）。

## 整体流程

```
需求文档（你给链接）
  ↓ Step 1
课程调研报告（飞书子文档）
  ↓ Step 2
课程体系设计（飞书子文档）
  ↓ Step 3
逐课教案（循环，每课一个飞书子文档）
  ↓ Step 4
练习/测验设计（飞书子文档）
```

**每步原则**：产出 → 展示 → 你审 → 确认/修改 → 下一步。

---

## Step 0: 读取需求文档

你给飞书文档链接，我：

1. 调 ffeishu 工作流 Step S 或直接 fetch 文档内容
2. 提取：课程主题、目标受众、受众水平、课程概览、核心方向
3. 问清你不确定的信息

确认理解后进入 Step 1。

---

## Step 1: 课程调研

> 产出：飞书子文档《<课程名>-调研报告》

### 调研框架

按 3 个课程方向选择调研框架：

**商业分析方向**：
- 行业现状与趋势
- 主流分析方法论（SWOT / PEST / 波特五力 / 商业画布）
- 常用工具与数据源
- 岗位能力要求
- 竞品课程分析（调 fresearchframe 搜索同类课程）

**数据分析方向**：
- 技术栈生态（SQL / Python / BI / 可视化）
- 方法论（CRISP-DM / A/B Test / 指标体系）
- 行业实践案例
- 竞品课程分析

**AI 能力方向**：
- AI 技术栈（LLM / RAG / Agent / 传统 ML）
- 应用场景与成熟度
- 工具链与平台
- 学习路径设计资源
- 竞品课程分析

**知识管理方向**：
- 方法论（SECI / Zettelkasten / PARA / CODE）
- 工具生态（笔记/知识库/AI 辅助）
- 实施案例
- 竞品课程分析

### 执行

1. 委派 fsearch skill 做三源并行搜索（中文/英文/深度）
2. 按对应方向框架整理
3. 输出调研文档 → 调 ffeishu 创建子文档
4. 展示链接 → 你审 → 改 → 确认

---

## Step 2: 课程体系设计

> 产出：飞书子文档《<课程名>-课程体系》
> 依赖：Step 1 调研报告

### 体系设计内容

1. **课程定位**：一句话定位、目标学员画像、前置知识要求
2. **学习目标**：课程级目标（按 Bloom 分类法）、模块级目标
3. **模块/章划分**：
   - 模块名 + 学习目标 + 知识点清单
   - 模块间依赖关系图
   - 推荐学习顺序
4. **各章结构**：
   - 章标题 + 学习目标 + 核心概念 + 实践任务 + 预计时长
5. **评估设计**：各章测验形式、课程级项目/案例
6. **时间线**：总时长 / 建议节奏 / 章节时长分配

### 执行

1. 基于调研报告设计体系
2. 重点模块：逐模块展示章节规划，每块你确认再下一块
3. 全部确认后飞书输出

---

## Step 3: 逐课教案（循环）

> 产出：每课一个飞书子文档《N-章标题》
> 依赖：Step 2 课程体系

### 每课流程

按 Step 2 的章节顺序，一课一课走：

1. **展示**：当前章标题 + 学习目标 + 知识点（你之前确认过的）
2. **生成教案**：调 fresearchframe/fsearch 补充素材 → 写教案
3. **教案结构**：
   - 学习目标（细粒度，可衡量）
   - 导入（故事/案例/问题）
   - 核心知识点（按逻辑顺序展开）
   - 实操/示例
   - 本章小结
   - 课后练习提示
4. **输出**：调 ffeishu 创建子文档（父文档 = 课程体系所在父文档的 token）
5. **审核**：展示链接 → 你审 → 改 → 确认
6. **下一课**：确认后自动进入下一课

**循环终止条件**：Step 2 中定义的所有章节完成。

### 内容辅助

- 需要图示（架构图/流程图）→ 委派 fdiagram skill
- 需要补充数据/资料 → 委派 fsearch skill

---

## Step 4: 练习/测验设计

> 产出：飞书子文档《<课程名>-练习与测验》
> 依赖：所有教案完成

### 设计内容

按课程体系中的评估设计，逐模块生成：

1. **每章测验**（10 题/章）：
   - 5 道知识点题（选择/判断/填空）
   - 3 道理解应用题（场景分析）
   - 2 道实操题（工具/代码/实施）
2. **课程级项目**：
   - 综合性场景题，跨章节
   - 数据/案例可提供
   - 评分标准 + 参考答案
3. **配套资源**：
   - 数据集（如涉及数据分析课程）
   - 代码框架模板
   - 推荐阅读/扩展资源

### 执行

1. 基于已完成的教案逐模块生成习题
2. 每模块展示 → 你审 → 改 → 下模块
3. 全部确认后飞书输出
